# Ainovel Publishing Pipeline

This context covers how AI-generated novel chapters move from the ainovel writer on the server into publish-ready artifacts for human-reviewed upload to Fanqie Writer.

## Language

**Source Chapter**:
A canonical Markdown chapter generated by ainovel and stored under the novel workspace. It is the only authoring source for downstream release artifacts.
_Avoid_: Raw export, publish file, draft text

**Completed Chapter**:
A source chapter that the writer has marked complete in `meta/progress.json` and is no longer considered in-progress.
_Avoid_: Finished draft, final chapter

**Release Artifact**:
A derived file generated from a completed chapter for publishing workflows, such as TXT, ZIP, manifest rows, or reports.
_Avoid_: Source file, original chapter

**Release Batch**:
The full set of release artifacts produced by one export run for a given novel.
_Avoid_: Deployment, build

**Manifest Entry**:
A structured record describing one completed chapter in the release batch, including hashes, counts, paths, and status.
_Avoid_: Index row, metadata blob

**Publish Status**:
The lifecycle state tracked for a chapter after export, such as `ready`, `synced`, `saved_draft`, or `published`.
_Avoid_: Step, progress flag

**Publish Report**:
A machine-readable and human-readable summary of one release batch, including counts, duplicates, skipped chapters, and artifact locations.
_Avoid_: Log, console output

**Chapter Sync**:
The transfer of a completed chapter version from the server release queue to the local publishing tool without changing platform state.
_Avoid_: Upload, publish

**Editor Fill**:
Placing a chapter title and body into the Fanqie chapter editor without saving or publishing it.
_Avoid_: Upload, publish

**Draft Save**:
Persisting the filled chapter in Fanqie as a non-public draft.
_Avoid_: Publish, submit

**Publication**:
Submitting a chapter through Fanqie so it becomes scheduled for release or publicly available according to platform workflow.
_Avoid_: Sync, fill, save

**Publication Verification**:
Confirming from the Fanqie chapter-management view that the intended chapter and content version reached the expected platform state.
_Avoid_: Successful click, assumed publish

**Legacy Published Chapter**:
A chapter published on Fanqie before the publishing workflow began tracking it. Its existence is accepted during bootstrap, but its content version has not yet been verified by the workflow.
_Avoid_: Published, verified chapter

**Legacy Draft**:
A Fanqie draft created before the publishing workflow began tracking it. It must be reconciled with the current source chapter before the workflow may continue past it.
_Avoid_: Saved draft, ready chapter

**Publishing Ledger**:
The durable record of chapter versions and the last Fanqie state that the workflow has verified. It records observations and attempts but does not replace Fanqie as the authority for platform state.
_Avoid_: Plugin cache, manifest, source of platform truth

**Verified Platform State**:
A Fanqie draft or publication state confirmed from the platform after an attempted transition. A button click or request completion alone is not a verified state.
_Avoid_: Submitted, assumed success

**Version Conflict**:
A mismatch between the current server source chapter version and a chapter version already saved or published on Fanqie. It requires explicit review and is never resolved by silent overwrite.
_Avoid_: Update available, sync pending
