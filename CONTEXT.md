# Ainovel Publishing Pipeline

This context defines the business language for moving completed Ainovel chapters into the Fanqie Writer platform as verified, quota-aware scheduled publications.

## Source and release language

**Source Chapter**:
A canonical Markdown chapter generated by Ainovel and stored under the novel workspace. It is the only authoring source for downstream release artifacts.
_Avoid_: Raw export, publish file, draft text

**Completed Chapter**:
A source chapter that the writer has marked complete and is no longer considered in-progress.
_Avoid_: Finished draft, final chapter

**Release Artifact**:
A derived file generated from a completed chapter for the publishing workflow, such as normalized text, a manifest row, or a report.
_Avoid_: Source file, original chapter

**Manifest Entry**:
A structured description of one completed chapter version, including its source hash, normalized text hash, counts, and release paths.
_Avoid_: Index row, metadata blob

**Chapter Version**:
The immutable content identity of a chapter represented by its normalized text hash. A chapter number alone never identifies a safe version to publish.
_Avoid_: Latest chapter, file copy

## Platform publication language

**Publish Status**:
The lifecycle state of a chapter in this workflow: `ready`, `synced`, `planned`, `reserved`, `filling`, `awaiting_ai_choice`, `submitted`, `scheduled`, `published`, `version_conflict`, or `blocked`.
_Avoid_: Step, progress flag

**Editor Fill**:
Placing a selected chapter number, title, and body into the Fanqie chapter editor before any platform submission.
_Avoid_: Upload, publish

**Publication Plan**:
A durable proposal mapping chapter versions to publication dates, times, quota units, and the policy choices that will be used for submission.
_Avoid_: Batch size, upload list

**Publication Slot**:
A configured local-time date and time at which Fanqie is intended to make a chapter public, such as 12:00, 20:00, or 22:00 in `Asia/Shanghai`.
_Avoid_: Run time, browser alarm

**Scheduled Publication**:
A platform state in which Fanqie has accepted a chapter and recorded a future publication slot. It is not the same as a successful click or a local plan.
_Avoid_: Queued, submitted

**Publication Verification**:
Evidence read back from Fanqie that the intended chapter version is in the expected scheduled or published state.
_Avoid_: Successful click, assumed success

**Platform Schedule Observation**:
Evidence that Fanqie shows a chapter number and publication slot, without yet proving that its title and body are the current source chapter version. It reserves quota but cannot by itself authorize adoption.
_Avoid_: Verified chapter, matching version

**Existing Schedule**:
A scheduled or pending Fanqie chapter found during reconciliation before this workflow creates a new submission.
_Avoid_: Duplicate task, stale cache

**Reserved Platform Chapter**:
An existing Fanqie row that has enough chapter/date evidence to reserve quota and prevent duplicate submission, while its body version remains unclaimed until reconciliation.
_Avoid_: Failed chapter, verified version

## Quota and policy language

**Publication-Day Quota**:
The maximum number of platform-counted text units that may become public on one calendar date for the configured account and work.
_Avoid_: Upload quota, sync limit

**Effective Daily Limit**:
The configured hard limit used by the planner for one publication date. The initial value for the current account is 9,999 units.
_Avoid_: Approximate limit, warning threshold

**Quota Unit**:
The normalized text quantity used by the planner when comparing a chapter with the effective daily limit. The workflow records the source count and the platform-observed result separately when they differ.
_Avoid_: Byte count, word count

**AI Declaration Policy**:
The per-work choice governing the Fanqie publication setting for whether AI assistance is declared, with explicit per-run override available.
_Avoid_: Global AI switch, hidden default

**Manual AI Pause**:
A non-failure pause at Fanqie's publication settings where the user explicitly selects the AI declaration before the same automation run continues.
_Avoid_: Automation failure, guessed AI choice

**Automation Run**:
One controlled attempt to reconcile, fill, submit, and verify one planned chapter version in a local logged-in browser.
_Avoid_: Macro, click script

**Blocked State**:
A durable state entered when identity, page structure, quota, dialog meaning, or platform result cannot be verified. A blocked chapter requires explicit intervention or a reviewed plan change before another mutation.
_Avoid_: Failed click, retryable error

**Reconciliation-Gated Resume**:
Explicitly reopening a blocked run only after checking that Fanqie has no conflicting draft, schedule, or publication. A post-mutation ambiguous run is reconciled rather than reset to the new-chapter path.
_Avoid_: Retry button, blind restart

**Reconciliation**:
The comparison of the source manifest, local ledger, and Fanqie chapter/draft/schedule state before creating or changing a platform submission.
_Avoid_: Refresh, rescan

## Authority and safety language

**Publishing Ledger**:
The durable local record of chapter versions, plans, attempts, observed platform states, and verification evidence. It coordinates the workflow but does not replace Fanqie as the authority for platform state.
_Avoid_: Plugin cache, source of truth for the platform

**Version Conflict**:
A mismatch between the current source chapter version and a version already saved, scheduled, or published on Fanqie. It requires explicit review and is never resolved by silent overwrite.
_Avoid_: Update available, sync pending

**Human Intervention**:
An explicit user action required for login, CAPTCHA, risk control, unknown UI state, version conflict, quota ambiguity, or a policy override. It is not used as a silent fallback after an unverified mutation.
_Avoid_: Manual workaround, ignored error
