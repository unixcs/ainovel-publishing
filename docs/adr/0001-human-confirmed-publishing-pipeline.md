# Human-confirmed publishing pipeline

**Status: superseded by ADR 0007**

The original phase-one boundary kept final save and publish actions under human control while the local browser handled copy-and-fill work. The user later approved an opt-in automated scheduled-publication mode; ADR 0007 supersedes this boundary for the known, verified flow while retaining human intervention for credentials, CAPTCHA/risk controls, unknown states, and conflicts.
