# Borrow concepts from public projects without importing unlicensed automation

**Status: accepted**

The reviewed public projects provide useful ideas for Fanqie page flow, local browser sessions, chapter reconciliation, and modular platform adapters, but the inspected repositories do not declare a usable open-source license. Some also rely on coordinate clicks, swallowed exceptions, fixed sleeps, and success bookkeeping before verification. We therefore keep the current companion/extension boundary and implement independently, borrowing only publicly observable workflow concepts and reusing code only when a compatible license and audited provenance are available.
