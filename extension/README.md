# Ainovel 番茄发布助手 Chrome 扩展

## 当前能力

- 连接 `127.0.0.1:8787` 的 Windows 本地助手。
- 读取作品和发布队列。
- 预览单章正文、版本和 Hash。
- 一次只向当前番茄章节编辑页填充一章。
- 在标题、正文或章节号已有冲突内容时拒绝覆盖。
- 填充后重新读取页面内容并校验。
- 不自动保存、不自动发布、不自动处理弹窗、不自动进入下一章。

## 开发加载

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录。
5. 从本地助手执行 `ainovel-publisher print-token`，把 Token 填入扩展设置。
