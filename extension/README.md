# Ainovel 番茄发布助手 Chrome/Edge 扩展

## 当前已实现

- 连接 `127.0.0.1:8787` 的 Windows 本地助手。
- 读取作品、章节版本和发布队列。
- 预览单章正文、版本和 Hash。
- 一次向当前番茄章节编辑页填充一章。
- 在标题、正文或章节号已有冲突内容时拒绝覆盖。
- 填充后重新读取页面内容并校验。
- 按实际发布日期执行 `9999` 字安全上限，发布时间可选 12:00、20:00（默认）或 22:00。
- 读取已有定时任务并先占用额度；必须再核对正文，才会接管为同一章节版本。
- 自动处理“下一步”、已知错别字提示、全面检测、AI 声明、定时设置和最终提交。
- “每章手动选择 AI”会停在发布设置页，等待用户选择后从原页面继续。
- 最终提交与平台回读分开记录；无法回读时进入阻塞，绝不按成功处理。
- 对登录失效等明确发生在页面修改前的阻塞，支持平台核对后的显式恢复。

## 自动发布模式（0.2.0，默认关闭）

自动发布模式会在用户批准发布计划后，按显式状态机执行：

1. 验证登录状态、作品和目标章节。
2. 打开作家专区并创建/恢复目标章节编辑页。
3. 填充并校验章节号、标题、正文和字数。
4. 点击“下一步”，只确认已识别的错别字提示。
5. 等待“全面检测”真实完成。
6. 校验发布设置、分卷、章节和 AI 声明策略。
7. 使用计划中的 `12:00`、`20:00` 或 `22:00`（`Asia/Shanghai`）创建定时发布。
8. 重新读取章节管理页，确认目标版本和定时状态后才记为成功。

登录失效、验证码、风控、未知弹窗、字数额度冲突、版本冲突或无法验证的结果都会暂停，不会盲点或假报成功。自动化不会读取账号密码，也不会把登录态上传到服务器。第一次真实运行前保持“自动执行”关闭，只手动触发一个未来章节验证页面选择器。

详细边界见 [`../docs/plan-boundaries.md`](../docs/plan-boundaries.md)，实现顺序见 [`../docs/implementation-plan.md`](../docs/implementation-plan.md)。

## 开发加载

1. 打开 Edge 或 Chrome 的扩展管理页（Edge：`edge://extensions`）。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录。
5. 从本地助手执行 `ainovel-publisher print-token`，把 Token 填入扩展设置。
6. 点击扩展管理页的“重新加载”，确认助手版本为 `0.2.0`。
7. 先打开番茄章节管理页，读取并核对已有定时任务，再生成计划。
8. 自动执行保持关闭；先手动执行一章并确认平台回读成功，之后再显式开启。
