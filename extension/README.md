# Ainovel 番茄发布助手（Edge / Chrome）

## 给新手：正常使用只走这一条路

首次使用：

1. Windows 本地助手保持运行，侧栏右上角显示蓝色 **已连接**。
2. 在 Edge 中正常登录番茄作家后台。插件不读取账号密码，也不会把登录态传到云服务器。
3. 在侧栏选择作品；展开“设置”选择每日字数上限、最早排程日期、12:00 / 20:00 / 22:00 发布时间及 AI 声明策略，然后保存。
4. 保持“后台自动执行”关闭，点击唯一的主按钮 **检查并处理下一章**。
5. 等插件自动完成：打开正确作品 → 等章节列表稳定 → 核对平台记录 → 计算额度和日期 → 新建/续接下一章 → 填入章节号、标题和正文 → 下一步 → 错别字提示 → 全面检测 → AI 声明 → 定时发布 → 回读验证。
6. 成功后，再点同一个主按钮处理下一章。无需先点“刷新状态”，也无需手工生成、批准或执行排程。

日常使用就是第 4、6 步。只有登录、验证码、风控、真实内容冲突或无法确认最终提交结果时才需要人工处理。

## 0.3.4 为什么填充后不再一闪被清空

番茄的新建章节页会先显示一个临时空编辑器，随后创建真实草稿 ID，并重新挂载标题和正文控件。0.3.3 看见临时编辑器后立即填入，肉眼会先看到完整内容，但一两秒后临时控件被替换，内容也随之消失；同时，这版番茄顶部的“下一步”是自定义 ByteDance 控件，并不一定是标准 HTML 按钮。

0.3.4 的规则是：

- 先等 URL 出现真实草稿 ID、标题/正文节点不再更换，而且顶部“下一步”文字已经挂载，再开始填充。
- 填完后必须让章节号、标题和完整正文连续保持 2.5 秒，瞬时匹配不再算成功。
- 如果同一个草稿只发生一次“新控件全空白”的重挂载，插件会安全重填一次；出现任何非空差异就停止，绝不覆盖。
- “下一步”最多等待 15 秒，只接受页面顶部、文字完全等于“下一步”的小型可点击控件；底部教程、弹窗和大容器全部排除。
- 点击前最后再核对一次章节号、标题和正文，任何变化都停止且不点击。

## 0.3.3 为什么不再需要反复点刷新

番茄后台是 SPA：页面标题、章节行和“新建章节”按钮不是同时出现。旧版一看到“章节管理”四个字就读取，可能把仍在加载的空页面误当成“平台没有该章”；随后即使没有点到任何按钮，也会错误地把章节锁成 `blocked`。

0.3.3 的规则是：

- 最多等待 15 秒，直到页面不再加载、“新建章节”可用，而且确实看到章节行（新书则必须看到明确的“暂无章节”），随后整张列表连续稳定。
- 只看到“章节管理”标题和“新建章节”按钮不算列表加载完成；只有上述稳定快照才能证明某章在平台不存在。
- “新建章节”会在同一次操作里等待挂载；支持真实按钮和小型自定义可点击控件，但拒绝仅包含这几个字的大容器。
- 页面明确返回 `mutationAttempted: false` 时，章节保持可重试，不再误锁成 `blocked`。
- 失败后立即重新读取章节和排程，侧栏不会再显示可执行的旧计划。
- 多个旧版误锁章节可以按稳定快照安全恢复，但始终回到原本最早的目标章节，不会跳章。
- 本地助手要求插件携带完全相同的版本号；更新文件后若 Edge 仍运行旧后台，它会在读取任何计划前收到 409 并被阻止，直到用户在扩展管理页重新加载。
- “下一步”和最终定时提交仍保持严格、失败即停的安全边界。

## 当前能力

- 连接 `127.0.0.1:8787` 的 Windows 本地助手，增量同步服务器章节。
- 读取作品、章节版本、Hash 和持久化发布账本。
- 自动识别并绑定每部作品真实的番茄数字作品 ID。
- 自动填充章节号、标题和正文，并在填充后重新读取校验。
- 标题、正文或章节号已有冲突内容时拒绝覆盖。
- 按实际发布日期执行 `9999` 字安全上限；发布时间可选 12:00、20:00（默认）或 22:00。
- 平台已有的发布、待发布、审核中或草稿记录会占用额度并被跳过，避免重复提交。
- 自动处理“下一步”、已知错别字提示、全面检测、AI 声明、定时设置和最终提交。
- “每章手动选择 AI”会安全暂停，用户选择后通过“处理本章”继续。
- 最终提交与平台回读分开记录；结果无法验证时停止，绝不盲目重试。
- “下一步”之后、最终提交之前的中断，只有在稳定列表确认该章不存在后才能恢复。
- 每本作品只有一份有效批准排程；旧排程不能抢跑或跳章。

## 两个按钮分别做什么

- **检查并处理下一章**：日常唯一入口，会读取、对账、排程并执行下一章。
- **处理本章**：只在你从章节队列明确选中某章时使用，例如继续 AI 手动选择或核对已有草稿。

“仅重新读取平台状态（不发布）”藏在只读详情里，仅用于查看诊断，不是正常发布步骤。

## 安全停止，不要盲点

出现以下情况时插件会停下：登录失效、验证码、风控、未知弹窗、内容冲突、单章/当日额度冲突、最终提交结果不明。此时先看侧栏提示；不要手改 SQLite，也不要重复点击番茄的最终发布按钮。

背景自动执行在升级后会自动恢复为关闭。先手动完成一次真实章节并看到平台日期/时间回读成功，再决定是否启用。

## 开发加载

1. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`）。
2. 开启“开发者模式”。
3. 选择“加载解压缩的扩展”。
4. 选择本仓库的 `extension` 目录。
5. 从本地助手执行 `ainovel-publisher print-token`，首次使用时填入 Token 并“保存并测试”。
6. 每次更新扩展文件后，在扩展管理页点一次“重新加载”。已打开的番茄标签页会通过适配器版本握手自动刷新。

详细边界见 [`../docs/plan-boundaries.md`](../docs/plan-boundaries.md)，实现记录见 [`../docs/implementation-plan.md`](../docs/implementation-plan.md)。
